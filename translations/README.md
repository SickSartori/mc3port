# Translations

## Português (Brasil): `pt-br.mc3patch`

Tradução: **João13 e cia** ([joao13traducoes.com](https://joao13traducoes.com)), version 1.0 of 19 October 2026, for the
Xbox game (USA disc).

- Administrador: João13
- Romhack: OAleex, Krisp, Godoy e HeitorSpectre
- Textos: João13
- Edição gráfica: niccbilac e João13
- Revisão: João13
- Ferramentas: Delutto (texto), HeitorSpectre e Aluigi (arquivos), OAleex (ISO)

Licence: [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), as published by its authors on Hugging Face
(`Joao13TraducoesDublagens/Traducao-XBOX`). mc3port converts their patch to its own format and does not change the
translation: `pt-br.mc3patch` holds, for each of the 588 files it changes, the difference from the disc's file (VCDIFF)
and the SHA-1s of both, so it contains no file of the game. mc3port makes the translated files from the player's own
disc the first time Português (Brasil) is chosen (`src/pc/translation.cpp`); the European and the USA discs both work.

Added to mc3port at the suggestion of [NAKADANI's video](https://youtu.be/i5IWJ2krkeo).
