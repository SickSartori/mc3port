# hud_redrawn

The pictures of the HUD setting **HD** (`hud_style = 2`): the game's HUD textures drawn again as shapes, eight times
larger, as PNGs with a palette that the game colours as it does its own (`external/xport`, `renderer_replacement_folder`).
Each is named after the hash of the game texture it replaces; a texture with no picture here stays the game's.

- Dials (Jetta and McLaren: `hud_speed_1`, `hud_speed_3`, `hud_tac_1`, `hud_tac_2`), radar, arrows, digits, the
  countdown, the side arcs, and the start's word in each language (VAI, GO, PARTEZ, ADELANTE, and the VAI of the
  Português (Brasil) translation).
- The numbers and words on the dials are in **Republika** by Apostrophic Laboratories (freeware; the font file is not
  in mc3port, only the pictures drawn with it).
- Not drawn yet: `hud_speed_2`, `hud_tac_3`, `hud_tac_4`, the buttons, the fonts.

A player's own pictures in `hud_redrawn` in the data folder (`Documents\mc3port`) go over these.
